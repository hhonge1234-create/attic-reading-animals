# 다락방 이웃들의 책장: 구글 스프레드시트 연결 방법 (5분)

1. 브라우저 주소창에 `sheets.new`를 입력해 새 스프레드시트를 만들고, 이름을 `다락방 이웃들의 책장`으로 바꿉니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 코드를 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣은 뒤 저장(⌘S)합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누르고, 유형 선택(톱니바퀴)에서 **웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르면 권한 승인 창이 뜹니다. 내 구글 계정을 고르고, "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동 → 허용**을 누릅니다.
6. 마지막 화면의 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 Claude에게 보내 주세요.

## 알아 두면 좋은 것
- 이용자들이 꽂은 책은 시트의 `books` 탭에 한 줄씩 쌓입니다. 이름, 이메일 같은 개인정보는 저장하지 않습니다.
- 부적절한 제목이 들어오면 그 줄을 지우면 됩니다. 1분 안에 사이트에서도 사라집니다.
- 시트는 만든 사람만 볼 수 있습니다. 사이트에는 동물별로 많이 꽂힌 책 12권씩만 보입니다.
